# Personal Portfolio Website

A modern, responsive personal portfolio and resume website built using **HTML5, CSS3, and JavaScript**.

The website is designed to showcase professional information, development skills, experience, projects, and contact details through a clean and interactive user interface.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern dark-themed UI
* Smooth scrolling navigation
* Mobile navigation menu
* Animated section reveal effects
* Hero section with portfolio introduction
* About Me section
* Experience timeline
* Projects showcase
* Skills section
* Contact section
* Dynamic copyright year

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts – Inter
* Intersection Observer API

## 📂 Project Structure

```text
portfolio/
├── index.html
├── style.css
└── script.js
```

## 🚀 Getting Started

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or build tools are required.

## 🎯 Purpose

This project serves as a personal portfolio/resume website for presenting web development skills, projects, experience, and professional contact information.

## 📱 Responsive

The website includes responsive layouts and a mobile navigation menu for a better experience across different screen sizes.
